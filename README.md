# Personal Portfolio

A responsive personal portfolio website showcasing my projects, skills, experience, and achievements.

## 🚀 About

This portfolio is designed to present my work and technical skills in a simple, interactive, and modern interface.

It includes sections for:

- About Me
- Projects
- Technical Skills
- Contact
- Social Profiles

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- EmailJS
- Swiper.js
- ScrollReveal.js
- Remix Icons

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Interactive navigation
- Project showcase
- Skills section with technology icons
- Scroll animations
- Custom cursor
- Contact form with EmailJS
- Smooth scrolling
- Active navigation links
- Scroll-to-top button
